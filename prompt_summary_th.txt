================================================================================
สรุปข้อกำหนดโครงการและ Master Prompt: StarFlex ERP 3D (Flexible Packaging Factory Simulator)
================================================================================

1. ภาพรวมและเป้าหมายโครงการ (Project Overview & Goal)
--------------------------------------------------------------------------------
- พัฒนาเว็บแอปพลิเคชันจำลองโรงงานและระบบวางแผนทรัพยากรองค์กร (ERP 3D Digital Twin Simulator) รูปแบบ Single Page Application (SPA)
- จำลองสายการผลิตโรงงานผลิตบรรจุภัณฑ์พลาสติกชนิดอ่อน (Flexible Packaging / Plastic Film Factory) ครบวงจร ตั้งแต่วัตถุดิบต้นน้ำ แปรรูปผ่านเครื่องจักร จนถึงการโหลดพาเลทสินค้าสำเร็จรูปขึ้นรถตู้คอนเทนเนอร์
- รองรับการทำงาน 2 โหมดการจำลองหลัก:
  1) Mode: Flow Only (Non-Linear Concurrent Digital Twin): ระบบจำลองคู่ขนานเสมือนจริงแบบไม่บล็อกเวลา เครื่องจักรและกองยานพาหนะทำงานพร้อมกันอย่างต่อเนื่อง
  2) Mode: Flow Details (Linear Step-by-Step ERP Ledger): ระบบจำลองแบบแจกแจงบัญชี ERP ทีละขั้นตอน ตรวจสอบสูตรคำนวณของเสีย (Station Waste %) และบันทึก Event Log การตัดสต็อกย้อนกลับ
- ภาษาบนหน้าจอ UI: ภาษาอังกฤษทั้งหมด (Labels, Buttons, Panels, Stepper, Tooltips, Event Logs) เพื่อคงมาตรฐานสากลของระบบ ERP


2. สถาปัตยกรรมระบบและโครงสร้างไฟล์แบบโมดูลาร์ (Technical Architecture & Modular Files)
--------------------------------------------------------------------------------
- ปรับปรุงโครงสร้างจากไฟล์เดี่ยว (Monolithic Single File 8,650 บรรทัด) เป็นสถาปัตยกรรมโมดูลาร์แยกไฟล์ (Modular Architecture) 100% Vanilla JavaScript (ES5/ES6) + CSS ไม่ต้องใช้ Build Tools หรือ Bundler ใดๆ รองรับ GitHub Pages ทันที:
  • index.html (~720 บรรทัด): โครงสร้าง DOM หลัก, แคนวาส 3D, แผงควบคุมคำสั่งผลิต, แผงตรวจสอบ Inspector, และแถบ Stepper
  • css/style.css (~1,335 บรรทัด): สไตล์ของระบบ UI ทั้งหมด, ธีมสว่าง/มืด (Light/Dark Themes), Responsive Layout, การ์ด KPI และ Badges
  • js/config.js (~320 บรรทัด): ค่าคงที่ระบบ, แค็ตตาล็อกวัตถุดิบ (MATERIAL_CATALOG), สเปกสถานี (STATIONS_CONFIG), พิกัดโซน (ZONES_CONFIG), ค่าสถานะกลาง (appState) และเวลาตั้งต้นของสถานี (DEFAULT_TIMING_MAP)
  • js/calculations.js (~190 บรรทัด): สูตรคำนวณเส้นทางผลิต (Routing), การคำนวณย้อนกลับตาม Yield/Waste %, ปริมาณวัตถุดิบที่ต้องใช้ (Backward MRP) และฟังก์ชันจัดรูปแบบตัวเลข
  • js/materials.js (~2,210 บรรทัด): ระบบพื้นผิว 3D, Procedural Canvas Textures (ลายฟิล์ม Hygiene, ถุงซอง Hygiene, กระสอบเม็ดพลาสติก, กล่องลูกฟูกคราฟต์, พลาสติกฟิล์มยืดพันพาเลท Stretch Wrap, ฉลากกล่อง Starflex), แร็คอุตสาหกรรม, พาเลทไม้ และโมเดลสินค้าสำเร็จรูป
  • js/machines/ (โฟลเดอร์โมเดลเครื่องจักรแยกไฟล์เฉพาะทาง 7 สถานี):
    - common.js: โครงสร้างร่วมของเครื่องจักร, ตู้ควบคุม HMI, มอเตอร์และระบบขับเคลื่อน, ลูกกลิ้งประคองฟิล์ม, ราวกันตก และแผงป้องกัน
    - blown-film.js: หอคอยเป่าฟิล์มหลายชั้น (Extrusion Tower), ระบบ Co-Extrusion 3 หัว, ถุงเรซินวางนอน 3 ถุง, ฟองฟิล์มสีขาวล้วน, กรงประคอง, A-frame, ทางวิ่งฟิล์มซิกแซก และแท่นม้วนเก็บคู่ Surface Winder
    - ink-mix.js: ถังผสมหมึกสแตนเลสพร้อมใบกวนความเร็วสูง, มอเตอร์ขับเคลื่อน, ท่อจ่าย Solvent และตู้ควบคุมคอนโซล
    - printing.js: แท่นพิมพ์กราเวียร์หลายป้อมสี (Multi-Station Rotogravure Press), ลูกกลิ้งแม่พิมพ์โครเมียม, ถาดหมึก, อุโมงค์อบแห้งลอยฟ้า และม้วนเก็บฟิล์มพิมพ์ลาย Hygiene
    - laminate.js: เครื่องเคลือบลามิเนตแบบแห้ง (Dry Laminator), แท่นคลายฟิล์มคู่, ถาดกาว, อุโมงค์ลมร้อน และม้วนลามิเนตเคลือบเงา
    - slit.js: เครื่องตัดสลิตแบ่งม้วนความแม่นยำสูง (VENUS III Duplex Slitter Rewinder), แท่นคลายม้วน Master Roll ไฮดรอลิกด้านหลัง, เพลากรอคู่ Duplex หน้าเครื่อง, ป้ายเสาน้ำเงิน VENUS III, จอแสดงความเร็ว LED เหนือศีรษะ และพาเลทวางม้วนสลิตแนวนอน 3 ชั้น
    - bag.js: สายการผลิตขึ้นรูปซอง 5 ขั้นตอน (5-Stage Bag Converting Line), เสาคลายม้วนพร้อมชุดปรับแรงตึง, โครงพับ V-Plow, แท่นซีลความร้อนก้นซองและขอบข้าง, มีดตัดโรตารี, สายพานลำเลียงสีเขียวพร้อมแผ่นกั้นอะคริลิกสีน้ำเงิน, ซองสำเร็จรูป 3 ซองวางตรงกลางสายพาน, กล่องลูกฟูกรับซอง และพนักงานบรรจุกล่องประจำท้ายสายพาน
    - spout.js: เครื่องเชื่อมฝาจุกอัลตราโซนิก (Ultrasonic Rotary Spout Inserter), กรวยป้อนฝาจุกแบบสั่นสะเทือน (Vibratory Bowl Feeder), แขนกลหยิบฝาจุก และพาเลทกล่องสำเร็จรูปข้างเครื่อง
    - index.js: จุดเชื่อมต่อและลงทะเบียนฟังก์ชันสร้างเครื่องจักรทั้งหมดเข้าสู่ระบบ Three.js
  • js/vehicles.js (~575 บรรทัด): กองยานพาหนะโลจิสติกส์, รถโฟล์คลิฟต์ถ่วงน้ำหนักสีเหลือง (RM 1, RM 2, FG, Delivery Forklifts), รถลากพาเลทมือโยกไฟฟ้า (Hand Pallet Truck 1 & 2) และรถบรรทุกตู้คอนเทนเนอร์เปิดข้างพร้อมโลโก้ Starflex
  • js/bays.js (~150 บรรทัด): ระบบช่องวางวัตถุดิบตีเส้นความปลอดภัย, ช่อง Infeed กรอบสีเหลือง (#facc15), ช่อง Outfeed กรอบสีเขียว (#22c55e), ตรวจสอบความพร้อมของ Input และการเคลียร์พาเลท
  • js/floor.js (~315 บรรทัด): พื้นคอนกรีตเรียบระดับเดียวกันทั่วโรงงาน, พื้นผิว Aggregate Grain และรอยต่อ Saw-Cut Expansion Joints, กรอบเส้นทาสีแบ่งโซน และลบเส้นประทางม้าลายออกตามคำสั่ง
  • js/scene.js (~1,320 บรรทัด): การตั้งค่า Three.js Scene, กล้อง PerspectiveCamera, ระบบแสง Ambient + DirectionalLight, ระบบเงา PCFSoftShadowMap, ป้ายชื่ออุตสาหกรรมฝังพื้น Style 1 (Industrial Floor Plates), กลุ่มต้นไม้สวนอุตสาหกรรม, และระบบควบคุมกล้อง (Orbit, Pan, Zoom, Raycaster)
  • js/labels.js (~250 บรรทัด): ระบบป้ายลอย 2.5D HTML Overlays สำหรับแสดงรหัสวัตถุดิบและสถานะพาเลท
  • js/paths.js (~300 บรรทัด): ระบบสร้างจุดพิกัด Waypoints สำหรับเส้นทางการวิ่งของรถยกและรถเข็นพาเลททุกคัน
  • js/simulation.js (~1,400 บรรทัด): เอนจินจำลองการผลิตแบบคู่ขนาน (Concurrent Pipeline Engine) และแบบตามลำดับ (Sequential Task Engine), วงรอบเวลางาน (Station Timing Cycle: inputMin / outputMin), กฎการยกวางของ และลูปเดินรถส่งของ
  • js/ui.js (~1,000 บรรทัด): ผูก Event Listeners, ปรับธีม Light/Dark/System, อัปเดตการ์ด KPI, แผง Inspector, แถบ Stepper, ตารางของเสีย และตารางตั้งเวลาเครื่องจักร
  • js/main.js (~35 บรรทัด): จุดเริ่มต้นของแอปพลิเคชัน (initApp) และ Animation Render Loop (requestAnimationFrame)


3. ทิศทางงานภาพ 3D และสไตล์ศิลป์ดิจิทัลทวิน (3D Visual & Art Direction)
--------------------------------------------------------------------------------
- สไตล์งานภาพ: Isometric Industrial Open-Floor Cutaway (โมเดลโรงงานแบบผ่าตัดขวาง โปร่งโล่ง สบายตา รายละเอียดคมชัดระดับดิจิทัลทวิน)
- ผังโรงงานเปิดโล่ง (Open-Floor Layout): ไม่มีกำแพงหรือผนังล้อมรอบ และไม่มีห้องกระจกควบคุม (Supervisor Control Office) เพื่อให้มุมมอง 360 องศาเห็นทุกแผนกได้อย่างสมบูรณ์
- พื้นโรงงานและลานคอนกรีตระดับเดียวกัน (Continuous Concrete Ground):
  • พื้นคอนกรีตผิวขัดเรียบระดับเดียวกันทั่วทั้งโรงงานและลานภายนอก (Y = 0.0) ไม่มีแท่นยกระดับ ไม่มีขอบขั้นบันได และไม่มีการสร้างถนนลาดยางมะตอย
  • พื้นผิวคอนกรีตผ่านการสร้าง Texture แบบโพรซีเชอร์ (Procedural Concrete Canvas Texture ขนาด 512x512) มีเม็ดกรวดทรายละเอียด (Aggregate Micro-Grain Noise), จุดเม็ดทรายสลับสี และเส้นร่องรอยต่อขยายคอนกรีต (Saw-Cut Expansion Joints) สวยงามสมจริง
- ลานจอดโหลดสินค้า (Truck Loading Yard): ลานคอนกรีตระดับพื้นราบเสมอกับพื้นโรงงาน (ไม่มี Bay, ไม่มีหลังคา Canopy, ไม่มียกพื้นสูง และไม่มีถนนแอสฟัลต์) มีเส้นทาสีเหลืองตีกรอบช่องจอดรถบรรทุก คันกั้นล้อคอนกรีต และช่องทางวิ่งของรถยก
- รถบรรทุกตู้คอนเทนเนอร์เปิดข้าง (Side-Door Container Truck):
  • ตู้สินค้าสีขาวสะอาดตาพร้อมแถบสีน้ำเงินรอยัลบลูที่ชายล่าง ฝั่งด้านข้างซ้ายมีช่องเปิดกว้าง 7.6 เมตร พร้อมประตูตู้เปิดข้าง 2 บานเปิดอ้ากว้างออก 105 องศา (Open Side Doors)
  • คานล็อกประตูโครเมียม และขอบธรณีประตูมีแถบสีเหลือง-ดำเตือนความปลอดภัย
  • ผนังตู้ฝั่งขวาพิมพ์ลายโลโก้ STARFLEX ความละเอียดสูงคมชัด พร้อมเปิดระบบ Polygon Offset เพื่อป้องกันปัญหาเส้นระนาบซ้อนทับกะพริบ (Z-Fighting) 100%
  • ภายในตู้สินค้าเป็นห้องบรรทุกโปร่งโล่ง มีโครงเหล็กหลังคา หลอดไฟส่องสว่าง และพื้นเหล็กลายตารางรองรับพาเลทสินค้า เพื่อให้รถยก Delivery Forklift ขับสอดงายกพาเลทเข้าไปวางในตู้รถได้โดยตรง และประตูจะปิดสนิทอัตโนมัติเมื่อรถบรรทุกออกเดินทางส่งของ
- ระบบแสงและเงาสัมผัสพื้นสมจริง (Realistic Ground Contact Shadows):
  • เปิดใช้งาน THREE.PCFSoftShadowMap ร่วมกับ DirectionalLight ที่ตำแหน่ง (70, 130, 85)
  • Shadow Camera Frustum ครอบคลุมพื้นที่โรงงานทั้งหมด 280m x 140m (ความละเอียด 4096 x 4096, bias -0.0005, normalBias 0.025, shadow.radius 2.5)
  • ปรับสมดุลแสงนุ่มนวล (ambientLight 0.84, dirLight 0.40) ทำให้เงาทอดสัมผัสพื้น (Contact Shadows) เป็นสีเทาอ่อนนุ่มตา ขอบเงานุ่มนวล ไม่ทึบดำจนบดบังรายละเอียดบนพื้นคอนกรีต
- การจัดกลุ่มต้นไม้รอบนอกโรงงาน (3 Perimeter Clustered Groves):
  • จัดวางต้นไม้เป็นกลุ่มสวนธรรมชาติ 3 จุดรอบนอกโรงงาน:
    1) จุดที่ 1 (ทิศตะวันตกเฉียงเหนือ): ด้านหลังคลัง RM WH
    2) จุดที่ 2 (ทิศตะวันออกเฉียงเหนือ): ด้านหลังคลัง FG WH & Yard
    3) จุดที่ 3 (ทิศใต้กึ่งกลาง): ด้านหน้าทางเข้าโรงงาน
  • แต่ละกลุ่มประกอบด้วยเกาะหญ้าขอบมน, ต้นไม้เรขาคณิต 5 ต้นลดหลั่นความสูง (3.5m - 5.2m) พร้อม 5 เฉดสีใบไม้ธรรมชาติ และพุ่มไม้เตี้ย 4 พุ่ม สวยงามลงตัวและไม่บดบังโรงงาน


4. ระบบป้ายชื่ออุตสาหกรรมฝังพื้น Style 1 (Industrial Floor Plates)
--------------------------------------------------------------------------------
- แทนที่ป้ายลอย 3 มิติแบบแคปซูลและลูกแก้วกลมเรืองแสง (Beacon Spheres) ด้วยแผ่นป้ายชื่ออุตสาหกรรมสไตล์ฝังแนบระดับพื้นคอนกรีต (Style 1: Industrial Floor Plate):
  • ตัวแผ่นป้าย: แผ่นโลหะสีขาวสว่างขอบมน (ขนาด 5.8m x 1.65m หนา 0.02m) พร้อมเงาตกกระทบรอบแผ่นป้าย, ขอบโลหะสีเงินสแตนเลส และหมุดรีเวตยึดสี่มุมที่มีรอยบากกากบาทสมจริง
  • แถบไฟสถานะ LED Accent: แถบสีแนวตั้งทางซ้ายของป้าย เปลี่ยนสีสดใสตามสถานะเครื่องจักร:
    - สีเขียว (#16a34a): สถานะ RUNNING (กำลังเดินเครื่องจักร)
    - สีน้ำเงิน (#2563eb): สถานะ DONE / COMPLETED (ผลิตเสร็จสิ้น)
    - สีส้มอำพัน (#d97706): สถานะ WAITING / WAITING_INPUT (กำลังรอวัตถุดิบเข้าช่อง Infeed)
    - สีเทา (#64748b): สถานะ IDLE / SKIPPED (เครื่องจักรว่าง หรือข้ามขั้นตอน)
  • ตัวอักษรบนป้าย: ตัวหนังสือสีเข้มคมชัดสูง (#0f172a) แสดงชื่อสถานี/โซนขนาดใหญ่ชัดเจน พร้อมป้ายแคปซูลแสดงสถานะ และคำบรรยายการทำงานด้านล่าง
  • ตำแหน่งติดตั้ง: วางแนบชิดบนพื้นคอนกรีต (Y = 0.035) โดยสถานีแถวที่ 1 (ทิศเหนือ) ป้ายจะถูกขยับขึ้นไปที่พิกัด Z = -8.2 เพื่อไม่ให้ทับซ้อนหรือสัมผัสกับกรอบช่องรับ-ส่งของ Infeed/Outfeed เด็ดขาด
  • ติดตั้งครอบคลุมทุกโซน: 4 คลังย่อยของ RM WH, 7 สถานีการผลิตของ PRD Line, คลังกลาง PRD WH และคลังสินค้าสำเร็จรูป FG WH & Yard


5. ผังโรงงาน 2 แถวและทางสัญจรสายกลาง (Two-Row Layout & Central Transit Highway)
--------------------------------------------------------------------------------
- ผังโรงงานวางตัวตามแนวนอนแบ่งเป็น 3 กลุ่มอาณาเขตหลัก:
  1) ส่วนซ้าย (X ≈ -63): คลังวัตถุดิบ RM WH (4 คลังย่อย)
  2) ส่วนกลาง (X ≈ 0): ฝ่ายผลิต PRD Line ผัง 2 แถว และคลังกลาง PRD WH
  3) ส่วนขวา (X ≈ +64): คลังสินค้าสำเร็จรูป FG WH & ลานจอดโหลดสินค้า (Truck Loading Yard)

- ผังการผลิต 2 แถว (Two-Row Machine Layout):
  • แถวที่ 1 (ทิศเหนือ / Z = -12.0):
    1. Blown Film (X = -30): เครื่องเป่าฟิล์ม
    2. Printing (X = -10): เครื่องพิมพ์กราเวียร์
    3. Bag (X = +10): เครื่องขึ้นรูปซอง
    4. Spout (X = +30): เครื่องติดฝาจุก
  • แถวที่ 2 (ทิศใต้ / Z = +12.0):
    1. Ink Mix (X = -30): สถานีผสมหมึก
    2. PRD WH (X = -10): คลังกลางสายการผลิต (Buffer & Curing)
    3. Laminate (X = +10): เครื่องเคลือบลามิเนต
    4. Slit (X = +30): เครื่องตัดสลิตแบ่งม้วน

- ทางสัญจรสายกลาง (Central Transit Highway: Z = 0.0):
  • ผิวคอนกรีตระดับเดียวกัน ลบเส้นประสีเหลืองทางม้าลายออกตามคำสั่งเพื่อความสะอาดตาและสมจริง
  • จุดรับ-ส่งของทุกสถานี (รวมถึง PRD WH) หันหน้าเข้าหาทางสัญจรสายกลางที่พิกัด Z = -5.2 (แถว 1) และ Z = +5.2 (แถว 2) โดยมีช่องว่างถนนสายกลางกว้าง 8.0 เมตร:
    - ช่อง INFEED (Input): อยู่ทางซ้ายเสมอ (X = X_station - 2.4) ตีกรอบเส้นสีเหลือง (#facc15)
    - ช่อง OUTFEED (Output): อยู่ทางขวาเสมอ (X = X_station + 2.4) ตีกรอบเส้นสีเขียว (#22c55e)
  • เลนเฉพาะทางวิ่งสวนกันได้ปลอดภัย ไร้การชน 100%:
    - เลนขาไปทางตะวันตก (Z = -1.8): สำหรับ RM Forklifts มุ่งหน้าสู่คลัง RM WH
    - เลนขากลับทางตะวันออก (Z = +1.8): สำหรับ Hand Pallet Trucks มุ่งหน้าสู่สถานีผลิต, PRD WH และคลัง FG


6. โครงสร้างคลังวัตถุดิบ RM WH (4 คลังย่อย พร้อมชั้นวาง 1 แถวและของวางบนพื้น)
--------------------------------------------------------------------------------
- คลังวัตถุดิบ RM WH แบ่งสัดส่วนออกเป็น 4 โซนย่อยพร้อมเส้นตีกรอบสีเหลืองบนพื้นคอนกรีต:
  1) Cylinder WH (บนซ้าย): แร็คอุตสาหกรรมเสาน้ำเงินคานส้ม ติดตั้งลูกกลิ้งแม่พิมพ์กราเวียร์สีดำด้าน 8 ลูก วางตั้งตรงแนวตั้ง (2 แถว x 4 ลูก)
  2) Chemical WH (บนขวา): ถังเคมีสีน้ำเงินเข้ม 4 ถัง (2x2), ถังสารเคมีสีเขียวมรกต 2 ถัง, และแถวหน้าถัง 4 ใบหลากสี (เหลือง 2, ส้ม 1, แดง 1)
  3) Supplies Used WH (ล่างซ้าย):
     • ชั้นวางของอุตสาหกรรม 1 แถว (ฝั่งตะวันตก): แร็ค 3 ชั้น เสาน้ำเงินคานส้มแผ่นชั้นสีขาว จัดวางแกนกระดาษคราฟท์สีน้ำตาล (PAPERCORE) แนวตั้ง 2 แถว x 3 อัน
     • สิ่งของจัดวางบนพื้นคอนกรีตโดยตรง (Floor Storage):
       - กองกล่องกระดาษลูกฟูก (BOX): กล่องสีน้ำตาลคราฟท์ 3 กล่องซ้อนกันบนพื้น ถัดจากแร็คไปทางขวา พร้อมแถบเทปขาวคาดบนกล่อง
       - กองกล่องฝาจุก (SPOUT): กล่องสีขาว 2 กล่องซ้อนกันบนพื้น ถัดจากกองกล่องลูกฟูกไปทางขวา
  4) Resin & Film Storage (ล่างขวา):
     • พาเลทไม้วางกระสอบเม็ดพลาสติก 25 กก. แนวนอน (Horizontal Resin Sacks) วางสลับชั้นขัดแตะ 4 ชั้น รวม 22 ถุงต่อพาเลท
     • ม้วนฟิล์มทรงกระบอกตั้งตรงบนพื้น 6 ม้วน (3 คู่สี: ขาว, ฟ้าพาสเทล, ม่วงพาสเทล)


7. บทบาทและโครงสร้างคลังกลางสายการผลิต PRD WH (Central Staging & Curing Buffer)
--------------------------------------------------------------------------------
- ตำแหน่ง: แถวที่ 2 ช่องที่ 2 (พิกัด X = -10.0, Z = +12.0)
- บทบาท: คลังกลางสำหรับวางของที่เอาไว้รอหรือพักวัตถุดิบและชิ้นงาน (WIP Buffer & Staging Area):
  1) พักบ่มตัวทางเคมี (Curing Area): ให้กาวลามิเนตเซ็ตตัวและสารทำละลายระเหยหมดก่อนส่งไปตัดสลิต
  2) พักรอคิวก่อนเข้าเครื่องจักร (WIP Buffer): ลดปัญหาคอขวดในสายการผลิต
  3) จัดเตรียมอุปกรณ์เสริม (Staging): ช่วยลดระยะทางการวิ่งของรถบนถนนสายกลาง
- โครงสร้างโมเดล 3D:
  • ช่องรับ-ส่งวัตถุดิบคู่หน้าคลัง: กรอบสีเหลือง Infeed (X = -12.4) และกรอบสีเขียว Outfeed (X = -7.6) ที่พิกัด Z = +5.2 หันหน้าเข้าหาทางสัญจรสายกลาง
  • หุ่นพนักงานประจำคลัง: ยืนตรงกลางด้านหลังช่องรับส่งของ หันหน้าขึ้นทิศเหนือ
  • แร็คอุตสาหกรรมวางเรียงหน้าคู่ขนาน (Dual Selective Racks): แร็ค 2 ชุดวางเคียงข้างกัน จัดวางถังเคมีสีเลือดหมูคาดฉลากขาว
  • แท่นวางม้วนฟิล์มพิมพ์ลายไฮยีน (Printed Roll Stand): ติดตั้งม้วนพิมพ์ลาย Hygiene พักรอก่อนเข้าเครื่องลามิเนต
  • แผ่นป้าย Industrial Floor Plate ฝังพื้นระบุชื่อ "PRD WH" พร้อมไฟ LED บอกสถานะ


8. คลังสินค้าสำเร็จรูปและลานจอดโหลดสินค้า (FG WH & Truck Loading Yard)
--------------------------------------------------------------------------------
- พื้นที่ปีกทิศตะวันออก (Zone 4: FG WH & Yard พิกัด X ≈ +64, Z ≈ 0):
  • แร็คจัดเก็บสินค้าสำเร็จรูป 4 แถว (4 FG Rack Rows): แร็คอุตสาหกรรม 3 ชั้น เสาน้ำเงินคานส้มแผ่นชั้นสีขาว รองรับพาเลทกล่องซองและพาเลทม้วนสลิตสำเร็จรูป
  • พาเลทกล่องสำเร็จรูปตั้งพื้น 2 พาเลท (Floor-Staged Pallets): พาเลทไม้วางกล่องกระดาษลูกฟูกสกรีนฉลาก Starflex พันฟิล์มยืดใส (Stretch Wrap) วางเตรียมพร้อมสำหรับการโหลดขึ้นรถ
  • ลานจอดโหลดสินค้าคอนกรีตระดับพื้นราบ: มีช่องจอดรถบรรทุกตีกรอบเส้นสีเหลือง คันกั้นล้อคอนกรีต และเส้นทางวิ่งของรถยก
  • รถยก FG Forklift: รับสินค้าสำเร็จรูปจากท้ายเครื่องจักร (Slit, Bag, Spout) มาจัดเก็บบนแร็ค FG
  • รถยก Delivery Forklift: เบิกพาเลทสินค้าจากแร็คและลานพัก ขับเข้าสอดงายกนำขึ้นตู้คอนเทนเนอร์ของรถบรรทุกโดยตรง


9. รายละเอียดโมเดลเครื่องจักร 7 กระบวนการ (Individual Machine Models)
--------------------------------------------------------------------------------
1) ST_BLOWN (Blown Film Extrusion Tower):
   • หอคอยโครงเหล็กนั่งร้านแนวตั้งสีขาวตัดขอบน้ำเงิน
   • ฝั่งขวา (+X): ระบบ Co-Extrusion กระบอกรีดแนวนอน 3 กระบอกขนานกัน พร้อมกรวยจ่ายเม็ดพลาสติกและหอจ่ายสารเติมแต่งสแตนเลส 4 ท่อ
   • กองถุงเม็ดพลาสติก 3 ถุง: ถุง 25 กก. วางแนวนอนกองอยู่บนพื้น 3 ถุง (ล่าง 2 ถุง บน 1 ถุง) ข้างกรวยจ่ายวัตถุดิบ
   • ส่วนกลาง: หัวดายเป่าฟิล์ม (Die Head) และวงแหวนหล่อเย็นลมคู่ Dual-Lip Air Ring
   • กรงประคองฟิล์มล่างและเกลียวประคอง, กระเช้าปรับขนาดฟิล์มช่วงกลาง (Calibration Basket)
   • ฟองฟิล์มเป่าทรงกระบอกสีขาวล้วน (White Tubular Film Bubble) โปร่งแสงทอดยาวขึ้นสู่ยอดหอคอย
   • ยอดหอคอย: ชานชาลาดาดฟ้า แผงรีดแบนทรงสามเหลี่ยม (A-Frame Slat Boards) และลูกกลิ้งดึงฟิล์ม Nip Rollers
   • ทางวิ่งฟิล์มซิกแซกแนวตั้ง (Descending Zig-Zag Dancer Web Path): แผ่นฟิล์มสีขาววิ่งผ่านลูกกลิ้งปรับความตึง 5 ระดับ
   • ฝั่งซ้าย (-X): แท่นม้วนเก็บฟิล์มคู่แบบ Surface Winder ม้วนฟิล์มที่ออกมาต้องเป็นสีขาวล้วน 100%

2) ST_INK (Ink Mixing Station):
   • โครงแท่นเหล็กผสมสีอุตสาหกรรมสีน้ำเงิน พร้อมราวกั้นนิรภัย
   • ถังสแตนเลสผสมหมึก 2 ถัง พร้อมมอเตอร์ขับเคลื่อนและเพลาใบกวนความเร็วสูง
   • ท่อจ่าย Solvent และตู้ควบคุมคอนโซลระบบสัมผัส

3) ST_PRINT (Rotogravure Printing Press):
   • ป้อมพิมพ์สีกราเวียร์เรียงแถวยาวหลายป้อมสี (Multi-Station Printing Units) สีน้ำเงินและเทาอุตสาหกรรม
   • ลูกกลิ้งแม่พิมพ์โครเมียม, รางหมึกพิมพ์, และอุโมงค์อบลมร้อนลอยฟ้า (Overhead Drying Oven Bridge)
   • แท่นคลายฟิล์ม Unwinder ด้านซ้าย: ม้วนฟิล์มที่นำเข้าต้องเป็นสีขาวล้วน 100% (Substrate White Roll)
   • แท่นม้วนเก็บ Rewinder ด้านขวา: ม้วนฟิล์มที่พิมพ์เสร็จหมุนเก็บเป็นม้วนพิมพ์ลาย Hygiene (ลายถุงปรับผ้านุ่มไฮยีน)

4) ST_LAM (Dry Laminator):
   • เครื่องเคลือบลามิเนตแบบแห้ง: แท่นคลายฟิล์มพิมพ์ลาย Hygiene ด้านล่าง และแท่นคลายฟิล์มประกบ (Barrier Film) ด้านบน
   • ถาดกาวลามิเนต, ลูกกลิ้งเกลี่ยกาว, อุโมงค์เป่าลมร้อนอบแห้งขนาดยาว และลูกกลิ้งอัดประกบฟิล์มด้วยความร้อน
   • ม้วนเก็บ Rewinder: ม้วนลามิเนตเคลือบเงาสูงพิมพ์ลาย Hygiene

5) ST_SLIT (VENUS III Duplex Slitter Rewinder):
   • ออกแบบตามภาพถ่ายอ้างอิงเครื่องตัดสลิต Venus III (HCI Converting Equipment):
   • ด้านหลัง (Input): ม้วน Master Roll พิมพ์ลาย Hygiene ขนาดใหญ่ ติดตั้งบนแขนยกไฮดรอลิกสีดำหนา
   • ด้านหน้า (Output): เพลากรอคู่แบบ Duplex Shafts ติดตั้งม้วนฟิล์มสลิตหน้าแคบ 2 ม้วนสลับตำแหน่งบน-ล่าง
   • แขนสวิงกลไกพร้อมกระบอกลมนิวเมติกและลูกกลิ้งยางสัมผัส (Lay-on Contact Rollers)
   • ใบมีดตัดโรตารีตรงกลาง, ลูกกลิ้งปรับความตึง และท่อดูดเศษขอบฟิล์ม
   • เสาขวา: เสาสีขาวขอบมน สกรีนตัวอักษรแนวตั้งสีน้ำเงิน "VENUS  III" พร้อมป้ายระบุเพลา [ 1 ] และ [ 2 ]
   • เสาซ้าย: ตู้ควบคุม HMI ระบบสัมผัส ปุ่มกด และสวิตช์ E-Stop
   • ป้ายแสดงความเร็ว LED เหนือศีรษะ: "SPEED: 480 m/min | TENSION: 24.5 N"
   • ด้านหน้าเครื่อง: พาเลทสี่เหลี่ยมวางม้วนสลิตสำเร็จรูปแนวนอน 3 ชั้น มีแผ่นกระดาษแข็งคั่นระหว่างชั้น

6) ST_BAG (5-Stage Bag Converting Line):
   • สายการผลิตซองอัตโนมัติความละเอียดสูง แบ่ง 5 ช่วงชัดเจนตามภาพถ่ายโรงงานจริง:
     - ช่วงที่ 1 (Rear Unwind Tower): เสาโครงเหล็กปรับแรงตึง Dancer Tower, ม้วนจัมโบ้ Master Roll ด้านบน (x = -4.35, y = 1.52) และม้วนฟิล์มพับก้นซองด้านล่าง พร้อมดิสก์เบรกระบายความร้อน แผ่นฟิล์มวิ่งขนานแกนเข้าสู่ลูกกลิ้งนำทางอย่างเที่ยงตรง
     - ช่วงที่ 2 (Forming & V-Plow): โครงเหล็กนำฟิล์มเข้าสู่แผงพับสามเหลี่ยมสแตนเลส V-Plow Guide Bars รีดพับฟิล์มประกบหน้า-หลังและสอดก้นซอง แผ่นฟิล์มวิ่งเรียบตึงไม่บิดเบี้ยว
     - ช่วงที่ 3 (Longitudinal & Cross Heat Sealing): แท่นซีลความร้อนขนาดยาวพร้อมกระบอกลมกดซีลก้นซอง, แท่งฮีตเตอร์ซีลขอบข้างแนวตั้ง, แท่นหล่อเย็นลดอุณหภูมิ, วงล้อปรับตั้งมือหมุนสีดำ (Spoked Handwheels) และบานตู้สแตนเลสพร้อมมือจับ
     - ช่วงที่ 4 (Rotary Cutter): ใบมีดตัดซองกิโยตินเซอร์โวมอเตอร์ ตัดแบ่งซองเดี่ยว พร้อมหัวดูดเศษฟอยล์
     - ช่วงที่ 5 (Outfeed Conveyor & Packing): โต๊ะสแตนเลสพร้อมสายพานลำเลียง PVC แบนสีเขียว (Green Belt Center Z = -0.05), แผ่นกั้นอะคริลิกสีน้ำเงิน, ซองสำเร็จรูปพิมพ์ลาย Hygiene 3 ซองวางตรงกลางสายพานเว้นระยะสวยงาม, กล่องลูกฟูกเปิดฝารองรับซองที่ปลายสายพาน, และหุ่นพนักงานบรรจุซองยืนประจำปลายสายพาน
   • ด้านข้างเครื่อง: พาเลทไม้วางกล่องสำเร็จรูปบรรจุซองพร้อมฟิล์มยืดใสพันพาเลท จัดวางในระยะที่ปลอดภัยไม่ทับซ้อนกับกล่องรับซองปลายสายพาน

7) ST_SPOUT (Ultrasonic Rotary Spout Inserter):
   • ตัวเครื่องสีเทาอุตสาหกรรม โครงเหล็กทึบพร้อมช่องกระจกมองการทำงาน
   • กรวยป้อนฝาจุกทรงกลมแบบสั่นสะเทือน (Vibratory Bowl Feeder) สแตนเลส บรรจุฝาจุกสีเขียวมรกต
   • รางป้อนฝาจุกและหัวเชื่อมอัลตราโซนิกความถี่สูง ติดตั้งฝาจุกเข้ากับมุมบ่าซอง Hygiene Spout Pouch
   • ด้านข้างเครื่องมีพาเลทกล่องสำเร็จรูปบรรจุซองติดฝาจุก


10. รถขนถ่ายสินค้าและกองยานพาหนะคู่ (Fleet Management & Zero-Teleport Dual Fleet)
--------------------------------------------------------------------------------
- ยกระดับกองยานพาหนะเป็นระบบคู่ (Dual Fleet System) ขจัดปัญหาการวาร์ปหายตัว (Zero-Teleportation) รถทุกคันวิ่งสัญจรต่อเนื่องตลอดสายการผลิต:
  1) รถโฟล์คลิฟต์ RM Forklifts จำนวน 2 คัน:
     • RM Forklift #1 (สีทอง Safety Gold #f59e0b): วิ่งเบิกจ่ายวัตถุดิบต้นน้ำจาก RM WH ไปยัง Infeed ของสถานี Blown Film, Ink Mix, Printing และ Laminate
     • RM Forklift #2 (สีส้ม Safety Orange #ea580c): วิ่งเก็บผลผลิตเข้าคลัง RM WH (ม้วน Blown Film, ถังหมึกผสม) และเบิกจ่ายวัสดุบรรจุภัณฑ์ไปยังสถานี Slit, Bag และ Spout
     • มีหุ่นคนขับ 3D สวมเสื้อกั๊กสะท้อนแสง, เสากระโดงคู่สีดำ และงายกยาวสีดำขนานพื้น
  2) รถลากพาเลทมือโยกไฟฟ้า Hand Pallet Trucks (HPT) จำนวน 2 คัน:
     • HPT Worker #1: รับผิดชอบลำเลียงม้วนพิมพ์ลายจาก Printing เข้าสู่คลังกลาง PRD WH เพื่อบ่มกาว (Curing) และเบิกม้วนที่บ่มได้ที่ส่งต่อไปยัง Laminate
     • HPT Worker #2: รับผิดชอบลำเลียงม้วนลามิเนตจาก Laminate เข้าสู่ PRD WH เพื่อบ่มกาว และส่งต่อไปยัง Slit -> Bag -> Spout
     • คนเข็นเดินตามคันโยกบนทางสัญจรสายกลาง วิ่งต่อเนื่องไม่หยุดนิ่ง
  3) รถโฟล์คลิฟต์สินค้าสำเร็จรูป FG Forklift (สีเหลือง #facc15):
     • ทำงานแบบอัจฉริยะตามประเภทออร์เดอร์:
       - ถ้าสั่งผลิตม้วน (FG_ROLL): รถจะวิ่งตรงไปรับพาเลทม้วนจากสถานี Slit ทันที
       - ถ้าสั่งผลิตซอง (FG_BAG): วิ่งไปรับพาเลทกล่องซองจากสถานี Bag
       - ถ้าสั่งผลิตซองติดฝาจุก (FG_SPOUT): วิ่งไปรับพาเลทกล่องซองจากสถานี Spout
     • นำสินค้าสำเร็จรูปไปจัดเก็บบนแร็ค FG 4 แถว
  4) รถโฟล์คลิฟต์โหลดตู้คอนเทนเนอร์ Delivery Forklift:
     • ตักพาเลทสินค้าจากแร็คและลานพัก FG ขับเข้าเทียบข้างรถบรรทุก สอดงายกพาเลทเข้าไปวางบนพื้นตู้รถคอนเทนเนอร์ผ่านประตูด้านข้าง
     • เมื่อวางสินค้าแล้ว สินค้าจะหลุดออกจากงายกและปรากฏอยู่ภายในตู้รถทันที


11. รถบรรทุกคอนเทนเนอร์เปิดข้างและระบบโหลดสินค้า (Side-Door Container Truck & Delivery System)
--------------------------------------------------------------------------------
- รถบรรทุกตู้คอนเทนเนอร์ Starflex (Starflex Logistics Semi-Trailer Truck):
  • หัวลากสีน้ำเงินรอยัลบลู (#1d4ed8) กันชนหน้าสีดำ ไฟหน้าสีเหลืองสว่าง
  • ตัวตู้สินค้าสีขาวสะอาดตา ด้านข้างขวาติดแผ่นป้ายโลโก้ STARFLEX คมชัดสูง
  • ด้านข้างซ้ายมีประตูเปิดข้าง 2 บานเปิดอ้ากว้าง 105 องศา ธรณีประตูคาดแถบสีเหลือง-ดำเตือนความปลอดภัย
  • ภายในตู้เป็นโครงสร้างโปร่ง มีพื้นเหล็กและหลอดไฟส่องสว่าง รองรับพาเลทสินค้าสำเร็จรูป 4 พาเลท
  • ลูปการส่งสินค้าต่อเนื่อง (Continuous Delivery Loop):
    1. รถยก Delivery Forklift ยกพาเลทเข้าตู้รถจนครบจำนวน
    2. ประตูตู้คอนเทนเนอร์ปิดสนิทอัตโนมัติ
    3. รถบรรทุกสตาร์ตเครื่องยนต์ มีควันไอเสียจิ๋ว ขับเดินหน้าออกจากลานจอดมุ่งหน้าสู่ถนนภายนอก
    4. รถบรรทุกวนรอบและกลับเข้ามาจอดเทียบที่ลานจอดเดิม ประตูเปิดอ้าออก พร้อมรับพาเลทในรอบการผลิตถัดไป


12. ระบบช่องรับ-ส่งวัตถุดิบ Infeed/Outfeed และ Logic การผลิต (Event-Driven Logistics & Timing)
--------------------------------------------------------------------------------
- กฎความสมจริง 3 ข้อของช่องวางวัตถุดิบ (3 Core Realism Rules):
  1) Input ต้องลงกรอบสีเหลือง และหลุดจากตัวรถ: เมื่อรถยกนำวัตถุดิบมาส่งที่ช่อง Infeed กรอบสีเหลือง (#facc15) ของจะหลุดออกจากงายกทันที และปรากฏวางอยู่ภายในกรอบสีเหลือง
  2) รับของจาก Output กรอบสีเขียว ของต้องไม่ค้างในกรอบ: เมื่อเครื่องจักรผลิตเสร็จ ผลผลิตจะวางในกรอบสีเขียว Outfeed (#22c55e) เมื่อรถยกหรือ HPT มารับไป ของจะถูกยกขึ้นตัวรถและเคลียร์หายไปจากกรอบสีเขียวทันที
  3) ไม่มี Input เครื่องหมุนเบา มี Input เดินเครื่องเร็ว:
     • หากช่อง Infeed สีเหลืองว่างเปล่า: เครื่องจักรจะเดินเครื่องเบา (Idle rotation 1.0 rad/s), ไฟ LED แถบสถานะเป็นสีส้ม/เทา, พนักงานประจำเครื่องพักนิ่ง
     • เมื่อวัตถุดิบมาวางที่ช่องสีเหลือง: เครื่องจักรจะเร่งความเร็วเต็มกำลังทันที (Active rotation 7.2 rad/s), ไฟ LED แถบสถานะเปลี่ยนเป็นสีเขียวสด, แขนพนักงานขยับทำงานอย่างกระฉับกระเฉง
- Logic การผลิตแบบ Event-Driven:
  • เครื่องจักรต้องมี Input ในกรอบสีเหลืองก่อน จึงจะเริ่มรอบการทำงานได้
  • หากยังไม่มี Output ในกรอบสีเขียว สถานีถัดไปหรือรถขนย้ายจะต้องจอดรอจนกว่าเครื่องจะผลิตเสร็จ
- การตั้งเวลาทำงานรายสถานี (Station Timing Configuration):
  • ผู้ใช้สามารถตั้งเวลาการทำงานของแต่ละเครื่องได้ 2 ค่า (หน่วยเป็นนาที):
    - inputMin: ระยะเวลาใช้งานวัตถุดิบจากช่องสีเหลืองจนหมด (เมื่อครบเวลา ของในช่องสีเหลืองจะหายไป)
    - outputMin: ระยะเวลาทำงานจนผลิตเสร็จและปล่อยชิ้นงานออกมาวางที่ช่องสีเขียว
  • ค่าตั้งต้นมาตรฐาน (Default Timing Map):
    - Blown Film: ใช้วัตถุดิบ 15 นาที / ผลิตเสร็จ 18 นาที
    - Ink Mix: ใช้วัตถุดิบ 10 นาที / ผลิตเสร็จ 12 นาที
    - Printing: ใช้วัตถุดิบ 20 นาที / ผลิตเสร็จ 25 นาที
    - Laminate: ใช้วัตถุดิบ 18 นาที / ผลิตเสร็จ 22 นาที
    - Slit: ใช้วัตถุดิบ 12 นาที / ผลิตเสร็จ 15 นาที
    - Bag: ใช้วัตถุดิบ 15 นาที / ผลิตเสร็จ 20 นาที
    - Spout: ใช้วัตถุดิบ 12 นาที / ผลิตเสร็จ 16 นาที
  • ปรับตั้งค่าได้ผ่านตารางควบคุมในแผงด้านซ้าย (#stationTimingGrid) และแสดงเวลานับถอยหลังสด (Live Countdown) ในแผง Inspector ด้านขวา


13. ลายสินค้าจริง Hygiene และมาตรฐานพาเลทกล่อง Starflex (Authentic Products & Pallets)
--------------------------------------------------------------------------------
- ลายพิมพ์ถุงปรับผ้านุ่มสูตรเข้มข้นพิเศษ "ไฮยีน" (Hygiene Expert Care):
  • ลายพิมพ์ความละเอียดสูงอ้างอิงจากถุงเติม 500 มล. จริง:
    - ด้านหลัง (Back Panel): แผงสีชมพูบานเย็นฟิวเชีย/มาเจนต้า (#be185d), โลโก้วงรีไฮยีน, คำอธิบายวิธีใช้, บาร์โค้ดขาว, มาร์คตัดเซนเซอร์ (Eye-marks) และจุดสี CMYK
    - ด้านหน้า (Front Panel): ไล่เฉดสีฟ้าครามไซแอนลงสู่ขาวมุก (#0284c7 -> #38bdf8 -> #ffffff), ริบบิ้นสีทอง (#f59e0b), โลโก้ตัวเขียน Hygiene ขอบเรืองแสงขาว, ตราเหรียญทอง 8X Freshness, ช่อดอกกุหลาบสีชมพูทับทิม, ป้ายระบุ REFILL 500 ml และประกายสะท้อนแสงเงา
  • ถ่ายทอดลายต่อเนื่องตลอดทั้งสายการผลิต: ม้วนฟิล์ม Rewinder ที่พิมพ์เสร็จ, ม้วนสเตจจิ้งใน PRD WH, ม้วนลามิเนต, ม้วนสลิตหน้าแคบ, และซองสำเร็จรูป 3 มิติบนสายพาน
- ข้อกำหนดม้วนฟิล์มสีขาวล้วนก่อนผ่านการพิมพ์ (Pure White Substrate Rolls):
  • ม้วนฟิล์มที่ออกจาก Blown Film และม้วนฟิล์มที่เบิกจากคลัง RM WH (Purchased Film) ก่อนจะเข้าสู่การพิมพ์ ต้องเป็นสีขาวล้วน (#ffffff / #f8fafc) ทั้งหมด 100%
- มาตรฐานพาเลทกล่องสินค้าสำเร็จรูป Starflex (Standardized Box Pallet Component):
  • โมดูลพาเลทมาตรฐานสร้างด้วยฟังก์ชัน `createStandardBoxPallet`:
    - พาเลทไม้ยูโร หรือพาเลทอุตสาหกรรมสีแดง
    - กล่องกระดาษลูกฟูกคราฟต์สีน้ำตาลทอง (#d4a373) เรียงซ้อนชั้นอย่างเป็นระเบียบ
    - แถบเทปกาวปิดผนึกสีขาวสว่างคาดตรงกลางผิวด้านบนของกล่อง
    - ฉลากสกรีนโลโก้ Starflex และรายละเอียดสินค้าติดที่ผิวด้านหน้าของกล่อง
    - ห่อหุ้มด้วยพลาสติกฟิล์มยืดใสกันฝุ่นรอบพาเลท (Ultra-Clear Stretch Wrap)
    - นำไปใช้งานเป็นมาตรฐานเดียวกันทั่วโรงงาน: จุด Outfeed ของ Bag และ Spout, แร็คคลังสินค้า FG, พาเลทตั้งพื้นลานพัก และสินค้าบนงายกรถโฟล์คลิฟต์


14. แผนผังเส้นทางการผลิต (Routing Engine & Backward Yield Calculation)
--------------------------------------------------------------------------------
- แหล่งที่มาของฟิล์ม (Film Source):
  • In-house Blown Film: เดินเครื่องเป่าฟิล์ม Blown Film นำม้วนฟิล์มสีขาวเข้าคลัง RM WH ก่อนส่งไปพิมพ์
  • Purchased Film: ข้ามขั้นตอน Blown Film โดยเบิกม้วนฟิล์มสำเร็จรูปสีขาวจาก RM WH ไปยังเครื่องพิมพ์โดยตรง
- เส้นทางการผลิตตามสินค้าสำเร็จรูป (3 Product Types):
  1) FG Roll (ม้วนฟิล์มพิมพ์สำเร็จ):
     Blown Film (ถ้าเลือก In-house) + Ink Mix -> Printing -> PRD WH (Curing) -> Laminate -> PRD WH (Curing) -> Slit -> FG WH & Yard
  2) FG Bag (ซองตั้ง Refill Pouch):
     Blown Film + Ink Mix -> Printing -> PRD WH -> Laminate -> PRD WH -> Slit -> Bag -> FG WH & Yard
  3) FG Spout (ซองติดฝาจุก Spout Pouch):
     Blown Film + Ink Mix -> Printing -> PRD WH -> Laminate -> PRD WH -> Slit -> Bag -> Spout -> FG WH & Yard
- ระบบคำนวณย้อนกลับตามของเสีย (Backward Yield Calculation Engine):
  • คำนวณปริมาณวัตถุดิบที่ต้องใช้จริงจากเป้าหมายผลผลิตปลายทาง (Target Output) ย้อนกลับทีละสถานีตามเปอร์เซ็นต์ของเสีย (Station Waste %):
    $$\text{Input}_{\text{step}} = \frac{\text{Output}_{\text{step}}}{1 - \frac{\text{Waste}\%}{100}}$$
  • ตัดสต็อกวัตถุดิบใน RM WH แบบไดนามิก (Resin, Film, Ink, Solvent, Adhesive, Cylinder, Papercore, Box, Spout)
  • แจกแจงยอดสูญเสียในแต่ละสถานีอย่างแม่นยำในแผง Station Waste Breakdown


15. ระบบจำลอง 2 รูปแบบ (Dual Simulation Engines: Concurrent vs Linear Ledger)
--------------------------------------------------------------------------------
1) Mode: Flow Only (Non-Linear Concurrent Digital Twin):
   • ออกแบบมาสำหรับการรับชมภาพเคลื่อนไหวโรงงาน 3 มิติที่มีชีวิตชีวาเสมือนจริงสูงสุด
   • สายการผลิตและสถานีทั้งหมดเดินเครื่องพร้อมกัน (Parallel Processing) ทันทีที่มีวัตถุดิบเข้าช่อง Infeed
   • กองยานพาหนะคู่ (RM Forklift 1 & 2, HPT 1 & 2, FG Forklift, Delivery Forklift) สัญจรต่อเนื่องบนถนนสายกลางโดยไม่มีการหยุดนิ่งหรือวาร์ป
   • คลังกลาง PRD WH ทำหน้าที่เป็นจุดบ่มและพักม้วนจริง โดยมีม้วนสะสมหลายม้วนพร้อมกัน
   • รถตู้คอนเทนเนอร์รับพาเลทจนเต็มตู้ แล้วขับออกไปส่งของเป็นวงรอบต่อเนื่อง
   • ซ่อนตารางตัวเลขและ Event Log บันทึกบัญชี เพื่อเปิดพื้นที่สายตารับชม 3D เต็มจอ

2) Mode: Flow Details (Linear Step-by-Step ERP Ledger):
   • ออกแบบมาสำหรับการตรวจสอบกระบวนการผลิตทางวิศวกรรมและการสอบย้อนกลับทางบัญชี ERP
   • จำลองการผลิตทีละขั้นตอนอย่างเคร่งครัดตามสเต็ป 1 ถึง 9 (Blown Film -> Ink Mix -> Printing -> Laminate -> Slit -> Bag -> Spout -> FG -> Delivery)
   • แสดงผลตารางตัดสต็อกคงเหลือใน RM WH, ตารางแจกแจงของเสียรายสถานี, และ Live Event Log บันทึกประวัติการเบิกจ่ายทุกวินาทีอย่างละเอียด


16. ส่วนต่อประสานผู้ใช้และการควบคุม (UI Controls, Stepper & Camera Navigation)
--------------------------------------------------------------------------------
- ธีมหน้าจอ (Theme Modes):
  • รองรับ 3 ธีม: Light (โหมดสว่าง - ค่าเริ่มต้นที่สบายตา), Dark (โหมดมืด), และ System (ตามการตั้งค่าของ OS)
  • จดจำค่าอัตโนมัติผ่าน LocalStorage (`sf_theme_mode`)
- แผงควบคุมคำสั่งผลิตและพาเนลลอยตัว (Collapsible Floating Panels):
  • หน้าต่างคำสั่งผลิตด้านซ้าย: เลือกประเภทสินค้า (FG Roll, FG Bag, FG Spout), ปริมาณการผลิต, หน่วยนับ (Roll, Meter, Kg, Pieces), แหล่งฟิล์ม (Inhouse / Purchased), สลับโหมด Minimal / Detailed
  • แผงควบคุมจำลอง: ปุ่ม Start/Pause มีไอคอนชัดเจน, ปุ่ม Reset ขอบแดง, ปุ่ม Follow Camera, ปุ่ม Loop Mode
  • ตัวปรับความเร็วการจำลอง: ปรับได้ 4 ระดับ (0.5x, 1x, 2x, 4x)
  • แผงตรวจสอบ Inspector ด้านขวา: แสดงข้อมูลเชิงลึกของสถานีหรือโซนที่คลิกเลือก, สต็อกวัตถุดิบ, สถานะเครื่องจักร, และตัวนับถอยหลังเวลาการผลิตสด

  • ปรับมุมมองอัตโนมัติ (Resize): ปรับสัดส่วนตามขนาดหน้าจอแบบ Responsive ทันที ไร้ปัญหาภาพบิดเบี้ยว
