================================================================================
สรุปข้อกำหนดโครงการ: Starflex ERP 3D (Flexible Packaging Factory Simulator)
================================================================================

1. ภาพรวมและเป้าหมายโครงการ (Project Overview & Goal)
--------------------------------------------------------------------------------
- พัฒนาเว็บแอปพลิเคชันจำลองการทำงานของโรงงานและระบบ ERP รูปแบบ 3 มิติ (Three.js 3D) หน้าเดียว (Single Page Application)
- จำลองสายการผลิตโรงงานบรรจุภัณฑ์พลาสติกชนิดอ่อน (Flexible Packaging / Plastic Film) ตั้งแต่การเบิกวัตถุดิบต้นน้ำ แปรรูปผ่านเครื่องจักร จนถึงการโหลดสินค้าสำเร็จรูปขึ้นรถตู้คอนเทนเนอร์
- รองรับการทำงาน 2 โหมดหลัก:
  1) Mode: Flow Only (ระบบจำลองคู่ขนานเสมือนจริงแบบไม่บล็อกเวลา / Non-Linear Concurrent Digital Twin)
  2) Mode: Flow Details (ระบบจำลองแบบละเอียดทางบัญชี ERP ทีละขั้นตอน / Linear Step-by-Step Ledger)
- ภาษาบนหน้าจอ UI: ภาษาอังกฤษ (Labels, Buttons, Panels, Stepper, Event Logs) เพื่อคงมาตรฐานระบบ ERP สากล


2. ทิศทางงานภาพ 3D (Stylized Isometric Industrial Digital Twin)
--------------------------------------------------------------------------------
- สไตล์งานภาพ: Isometric Industrial Architectural Cutaway (โมเดลโรงงาน 3 มิติแบบผ่าตัดขวาง โปร่งโล่ง สบายตา รายละเอียดคมชัดระดับดิจิทัลทวิน)
- ผังโรงงานเปิดโล่ง (Open-Floor Layout): ไม่มีกำแพงหรือผนังล้อมรอบโรงงาน และไม่มีห้องควบคุม Supervisor Control Office เพื่อเปิดมุมมองดิจิทัลทวินแบบ 360 องศา เห็นทุกโซนและทุกสถานีชัดเจน โปร่งโล่ง สบายตา
- พื้นโรงงานและลานทั้งหมด: พื้นคอนกรีตเรียบระดับเดียวกันทั้งหมดสีเทาอ่อนสะอาดตา (#e2e8f0 สว่าง / #1e293b มืด)
- ลานจอดโหลดสินค้า (Truck Loading Yard): ไม่ต้องมี Bay และไม่ต้องสร้างถนน เป็นลานจอดระดับพื้นคอนกรีตราบเรียบเสมอกับพื้นโรงงาน มีเส้นทาสีเหลืองตีกรอบช่องจอดรถบรรทุก คันกั้นล้อ และเส้นทางวิ่งของรถยก
- รถบรรทุกตู้คอนเทนเนอร์เปิดข้าง (Side-Door Container Truck): ตัวตู้สินค้าสีน้ำเงินด้านข้างฝั่งซ้าย (หันหน้าเข้าหารถยก Delivery Forklift) มีประตูตู้เปิดข้าง 2 บานเปิดอ้ากว้างออก 105 องศา (Open Side Doors) พร้อมแถบสีเหลือง-ดำเตือนความปลอดภัยที่ขอบธรณีประตู ภายในตู้เป็นห้องบรรทุกสินค้าโปร่งโล่ง มีโครงเหล็กหลังคา หลอดไฟส่องสว่าง และพื้นเหล็กรองรับพาเลทสินค้า เพื่อให้รถยก (Delivery Forklift) สามารถขับเข้ามาสอดงายกนำพาเลทสินค้าบรรจุภัณฑ์เข้าตู้รถผ่านทางประตูด้านข้างได้โดยตรง และประตูจะปิดสนิทอัตโนมัติเมื่อรถบรรทุกออกเดินทางส่งของ
- ชั้นวางสินค้า (Rack Model): แร็คอุตสาหกรรม 3 ชั้น เสาแนวตั้งสีน้ำเงินเข้ม (#1d4ed8) คานยึดข้างสีขาว คานรับน้ำหนักแนวนอนสีส้ม (#f97316) และแผ่นปูพื้นชั้นวางสีขาวสว่างทุกชั้น บนชั้นวางจัดวางถังเคมีสีเลือดหมูคาดฉลากขาวและกล่องลูกฟูกคาดเทปขาว
- รถโฟล์คลิฟต์ (Forklift Model): ตัวถังสีเหลืองนิรภัย (#facc15) ท้ายมีก้อนถ่วงน้ำหนักสีดำยกสูง, โครงหลังคาสี่เสาสีดำ, มีหุ่นพนักงานขับขี่สวมเสื้อกั๊กสะท้อนแสงสีเหลืองแขนน้ำเงินจับพวงมาลัย, เสากระโดงคู่สีดำด้านหน้า และงายกสีดำยาว 2 ข้างยื่นขนานระดับพื้น
- หุ่นพนักงาน: หุ่น 3 มิติจิ๋วสวมเสื้อกั๊กสะท้อนแสงสีเหลืองนีออน (#facc15) และหมวกนิรภัย
- แผง UI สะอาดตา (เลิกใช้ Backdrop Blur): หน้าต่าง แถบเมนู และการ์ดควบคุม UI ทั้งหมดใช้พื้นหลังทึบเรียบเนียน ไม่ใส่เอฟเฟกต์ backdrop-filter: blur() เพื่อให้อ่านข้อมูลง่าย สบายตา และประหยัดทรัพยากร GPU
- การจัดต้นไม้แบบกลุ่ม 3 จุดรอบนอกโรงงาน: จัดต้นไม้เป็นกลุ่มสวนธรรมชาติ (Tree Clusters) 3 จุดรอบนอก (ทิศตะวันตกเฉียงเหนือหลัง RM WH, ทิศตะวันออกเฉียงเหนือหลัง FG และทิศใต้ด้านหน้าโรงงาน) แต่ละกลุ่มมีเกาะหญ้าทรงกลม ต้นไม้ 5 ต้นหลากขนาดหลายเฉดสีเขียว และพุ่มไม้เตี้ย 4 พุ่ม สวยงามลงตัวและไม่บดบังโรงงาน
- ระบบเงาสัมผัสพื้นสมจริง (Realistic Ground Contact Shadows): เปิดใช้งาน THREE.PCFSoftShadowMap พร้อมตั้งค่าแสง DirectionalLight และขยายขนาด Shadow Camera Frustum ครอบคลุมพื้นที่โรงงานทั้งหมด 280m x 140m (ความละเอียด 4096 x 4096, bias -0.0005, normalBias 0.025, shadow.radius 2.5) ปรับสมดุลแสง (ambientLight 0.84, dirLight 0.40) ให้เงาทอดตกกระทบเป็นสีเทาอ่อนนุ่มตา ไม่เข้มทึบจนเกินไป ร่วมกับฟังก์ชัน applyShadowFlags ทำให้โมเดลเครื่องจักรทุกเครื่อง ชั้นวาง แร็ค ถังเคมี พาเลท รถโฟล์คลิฟต์ รถบรรทุก คนงาน และกลุ่มต้นไม้ ทอดเงาสัมผัสพื้น (Contact Shadows) ตกกระทบลงบนพื้นโรงงานและลานคอนกรีตได้อย่างนุ่มนวล คมชัด มีมิติสมจริง และไร้ปัญหาเงามัวหรือเงาแตกกระพริบ


3. ผังโรงงาน 2 แถวและถนนสายกลาง (2-Row Layout & Central Transit Highway)
--------------------------------------------------------------------------------
- โรงงานวางตัวตามแนวนอน แบ่งเป็น 3 ส่วนหลัก:
  1) ส่วนซ้าย: คลังวัตถุดิบ RM WH มี 4 คลังย่อย
  2) ส่วนกลาง: ฝ่ายผลิต PRD Line ผัง 2 แถว
  3) ส่วนขวา: คลังสินค้าสำเร็จรูป Warehouse FG & ลานจอดโหลดสินค้า (Truck Loading Yard)

- ผังการผลิต 2 แถว (Two-Row Machine Layout):
  • แถวที่ 1 (ทิศเหนือ):
    1. Blown Film (เครื่องเป่าฟิล์ม)
    2. Printing (เครื่องพิมพ์กราเวียร์)
    3. Bag Making (เครื่องทำซอง Pouch)
    4. Spout Applicator (เครื่องติดฝาจุก)
  • แถวที่ 2 (ทิศใต้):
    1. Ink Mix (สถานีผสมหมึก)
    2. PRD WH (คลังกลางสายการผลิต)
    3. Laminate (เครื่องเคลือบลามิเนต)
    4. Slit (เครื่องตัดสลิตแบ่งม้วน)

- ทางสัญจรสายกลาง (Central Transit Corridor):
  • พื้นคอนกรีตระดับเดียวกันทั่วทั้งโรงงาน (ไม่มีถนนแอสฟัลต์แยก) มีเส้นประสีเหลืองแบ่งกึ่งกลางตลอดแนว (พิกัด Z = 0.0, X = -86 ถึง +82) (ลบทางม้าลายออก)
  • จุดรับ-ส่งของทุกเครื่องจักร (รวมถึง PRD WH) หันเข้าหาทางสัญจรสายกลางที่พิกัด Z = -5.2 (แถว 1) และ Z = +5.2 (แถว 2) โดยมีช่องทางวิ่งสายกลางกว้าง 8.0 เมตร:
    - ช่อง INFEED (Input): อยู่ทางซ้ายเสมอ (X = X_station - 2.4) ตีกรอบสีเหลือง (#facc15) วัตถุดิบนำเข้าของทุก Process ต้องเข้าไปส่งลงที่กรอบสีเหลืองนี้เสมอ
    - ช่อง OUTFEED (Output): อยู่ทางขวาเสมอ (X = X_station + 2.4) ตีกรอบสีเขียว (#22c55e) ผลผลิตที่ผลิตเสร็จเมื่อจะส่งไปที่ใดต่อต้องออกจากกรอบสีเขียวนี้เท่านั้น
  • เลนเฉพาะทางวิ่งสวนกันได้โดยไม่ชนกัน:
    - เลนขาไปทางตะวันตก (Z = -1.8) สำหรับ RM Forklift (มุ่งหน้าไปทางทิศตะวันตก -X สู่คลัง RM WH)
    - เลนขากลับทางตะวันออก (Z = +1.8) สำหรับ Hand Pallet Truck (มุ่งหน้าไปทางทิศตะวันออก +X สู่สถานีผลิต, PRD WH และคลัง FG)
    - ระยะห่างระหว่างกึ่งกลางเลน 3.6 เมตร (ระยะห่างระหว่างตัวรถขณะวิ่งสวนกัน > 2.0 เมตร) มั่นใจได้ว่าวิ่งสวนกันได้อย่างปลอดภัย ไร้การชน 100%


4. โครงสร้างคลังวัตถุดิบ RM WH (4 คลังย่อย)
--------------------------------------------------------------------------------
RM WH แบ่งสัดส่วนการจัดเก็บออกเป็น 4 โซนย่อยพร้อมเส้นตีกรอบสีเหลืองบนพื้นคอนกรีต:
1) Cylinder WH (บนซ้าย): แร็คเสาน้ำเงินคานส้ม ติดตั้งลูกกลิ้งแม่พิมพ์กราเวียร์สีดำ 8 ลูกตั้งตรงแนวตั้ง (2 แถว x 4 ลูก)
2) Chemical WH (บนขวา): ถังเคมีสีน้ำเงินเข้ม 4 ถัง (2x2), ถังสีเขียว 2 ถัง และแถวหน้าถัง 4 ใบหลากสี (เหลือง 2, ส้ม 1, แดง 1)
3) Supplies Used WH (ล่างซ้าย): แร็คแขวนแกนกระดาษคราฟต์ 4 แกน, กล่องลูกฟูกซ้อน 2 ชั้นคาดเทปกาวขาว และถาดใส่ฝาจุก Spout
4) Resin & Film Storage (ล่างขวา): กองถุงเม็ดพลาสติกสีขาว และม้วนฟิล์มทรงกระบอกตั้งตรง 6 ม้วน (3 คู่สีพาสเทล: ขาว, ฟ้า, ม่วง)
- รถโฟล์คลิฟต์ RM Forklift สีเหลืองจอดประจำปากทางเข้าฝั่งขวา หันหน้างาไปทางทิศตะวันตกเข้าสู่ตัวคลัง


5. โครงสร้างและบทบาทของคลังกลางสายการผลิต PRD WH (Central Staging & Curing Buffer)
--------------------------------------------------------------------------------
- ตำแหน่ง: แถวที่ 2 ช่องที่ 2 (พิกัด X = -15, Z = +12)
- หน้าที่เป็น "คลังกลางสำหรับวางของที่เอาไว้รอหรือพักวัตถุดิบและชิ้นงาน (Buffer & Curing)":
  1) พักรอคิวก่อนเข้าเครื่องจักร (WIP Buffer)
  2) ลานบ่มตัวทางเคมี (Curing Area) ให้กาวลามิเนตเซ็ตตัวและสารทำละลายระเหยหมด
  3) พื้นที่จัดเตรียมอุปกรณ์เสริม (Staging) ช่วยลดระยะทางวิ่งบนถนนสายกลาง
- โครงสร้างและองค์ประกอบภาพ 3D (Reference Image Layout):
  • ด้านหน้าคลังหันเข้าหาทางสัญจรสายกลาง: ติดตั้งคู่กล่องสี่เหลี่ยมกรอบเส้นสีเหลืองโปร่ง 2 ช่องคู่กัน (2.4m x 2.4m) บนพื้นคอนกรีตโดยตรง ที่พิกัด Z = +5.2 (กล่องซ้าย Infeed ที่ X = -17.4, กล่องขวา Outfeed ที่ X = -12.6) เหมือนกับสถานีอื่นทุกประการตามภาพอ้างอิง
  • หุ่นพนักงานประจำคลัง: ยืนตรงกลางด้านหลังกล่องสีเหลืองทั้งสอง (X = -15, Z = +7.2) หันหน้าขึ้นทิศเหนือเข้าหาทางสัญจรสายกลาง
  • แร็คอุตสาหกรรมวางเรียงหน้าคู่ขนาน (Dual Side-by-Side Selective Racks): แร็ค 2 ชุดวางเรียงข้างกันด้านหลังพนักงาน บนแท่นพื้นรองสีเหลืองนิรภัย (#facc15) เสาแนวตั้งสีน้ำเงินเข้ม (#1d4ed8), คานรับน้ำหนักแนวนอนสีส้ม (#f97316), แผ่นปูพื้นชั้นวางสีขาวสว่าง (#f8fafc) ทุกชั้น
  • สินค้าที่จัดเก็บ: ชั้นล่างของทั้ง 2 แร็คจัดวางพาเลทไม้พร้อมถังเคมีสีเลือดหมูคาดฉลากกราฟิกสีขาว (Burgundy Drums with White Graphic Labels)
  • แท่นวางม้วนฟิล์มพิมพ์ลายด้านซ้าย (Left Printed Roll Stand): แท่นโลหะสีเข้มพร้อมม้วนฟิล์มพิมพ์ลายไฮยีน (Hygiene Expert Care) หน้าตัดสีชมพูอ่อนและแกนเพลา
  • ป้ายระบุตำแหน่ง 3D Floating Tag: ป้ายทรงแคปซูล `• PRD WH` มีจุดกลมสีเทาและตัวอักษรคมชัด ลอยเด่นหน้าคลังในแนวเดียวกับป้ายสถานีอื่น


6. รายละเอียดโมเดล 3D และช่องวางวัตถุดิบ (Infeed / Outfeed Bays)
--------------------------------------------------------------------------------
- โมเดลเครื่องจักรความละเอียดสูง:
  • Blown Film Extruder: หอคอยนั่งร้านแนวตั้ง, หัวดายเป่าลูกโป่งฟิล์ม, ม้วนเก็บฟิล์มคู่
  • Ink Mix: โครงเหล็กแท่นผสม, ถังสแตนเลสพร้อมมอเตอร์ใบกวน, ท่อจ่ายสารละลาย
  • Rotogravure Printing: ป้อมพิมพ์สีหลายป้อม, ลูกกลิ้งโครเมียม, สะพานแผ่นฟิล์มด้านบน
  • Laminator: ป้อมปล่อยฟิล์มคู่, ถาดกาว, อุโมงค์ลมร้อน, ลูกกลิ้งประกบฟิล์ม
  • Slitter Rewinder: เพลาใบมีดหมุนกลม, ท่อดูดเศษขอบ, เพลากรอม้วนคู่
  • Bag Making: แผ่นสามเหลี่ยมพับก้นซอง, แท่งซีลความร้อน, มีดตัด, สายพานส่งออก
  • Spout Applicator: ตัวเครื่องสีเทาอุตสาหกรรม, ชามป้อนฝาจุกแบบสั่น, หัวเชื่อมเชื่อมอัลตราโซนิก
  • ซองบรรจุภัณฑ์: ซองฟอยล์ตั้งได้มีก้นซองประกายเมทัลลิก และซองติดฝาจุกพลาสติกปากซอง
- ช่องตีกรอบสีเหลืองมาตรฐานความปลอดภัย (Demarcated Infeed & Outfeed Bays):
  • ทุกสถานี (รวมถึง PRD WH) มีคู่ของกล่องสี่เหลี่ยมกรอบเส้นสีเหลืองโปร่ง (2.4m x 2.4m, #facc15) วางแนบชิดระดับพื้นคอนกรีตโดยตรง (ไม่มีแผ่นพื้นหนาสีเข้มภายใน)
  • กล่องซ้าย = ช่อง INFEED (X = X_station - 2.4): ช่องรับวัตถุดิบนำเข้า
  • กล่องขวา = ช่อง OUTFEED (X = X_station + 2.4): ช่องจ่ายชิ้นงานที่ผลิตเสร็จ
  • หุ่นพนักงานประจำสถานียืนตรงกลางด้านหลังกล่องสีเหลือง หันหน้าเข้าหาทางสัญจรสายกลาง (Z = -7.2 สำหรับแถว 1, Z = +7.2 สำหรับแถว 2)
  • ช่องเปล่าจะโชว์พื้นคอนกรีตสะอาดตา ช่องที่มีงานจะวางพาเลทไม้พร้อมวัตถุดิบ 3D (เช่น Outfeed ของ Blown Film และ Ink Mix ตามภาพอ้างอิง) พร้อมป้าย 3D Floating Tags `In:` และ `Out:` ลอยอยู่เหนือกึ่งกลางกล่องอย่างชัดเจนสวยงาม


7. แผนผังเส้นทางการผลิต (Routing)
--------------------------------------------------------------------------------
- แหล่งที่มาของฟิล์ม (Film Source):
  • In-house Blown Film: เดินเครื่อง Blown Film เป่าม้วนฟิล์มแล้วนำเข้า RM WH ก่อนส่งพิมพ์
  • Purchased Film: ข้ามขั้นตอน Blown Film โดยเครื่องพิมพ์จะเบิกฟิล์มสำเร็จรูปจาก RM WH โดยตรง
- เส้นทางการผลิตตามสินค้า:
  • FG Roll:  Blown Film + Ink Mix -> Printing -> PRD WH -> Laminate -> PRD WH -> Slit -> Warehouse FG
  • FG Bag:   Blown Film + Ink Mix -> Printing -> PRD WH -> Laminate -> PRD WH -> Slit -> Bag -> Warehouse FG
  • FG Spout: Blown Film + Ink Mix -> Printing -> PRD WH -> Laminate -> PRD WH -> Slit -> Bag -> Spout -> Warehouse FG


8. ระบบจำลอง 2 รูปแบบ (Dual Simulation Engines)
--------------------------------------------------------------------------------
1) Mode: Flow Only (Non-Linear Concurrent Digital Twin):
   - เครื่องจักรในสายการผลิตเดินเครื่องพร้อมกัน (Parallel Processing) ทันทีที่มีวัตถุดิบในช่อง Infeed
   - ยานพาหนะปฏิบัติงานคู่ขนานกัน:
     • RM Forklift วิ่งเติมวัตถุดิบเข้า Infeed (เลน Z = -1.2)
     • Hand Pallet Truck ลำเลียงม้วนระหว่างสถานีและเข้า/ออก PRD WH (เลน Z = +1.2)
     • FG Forklift เก็บสินค้าสำเร็จรูปขึ้นแร็ค FG
     • Delivery Forklift ยกพาเลทขึ้นรถตู้คอนเทนเนอร์
   - รถตู้คอนเทนเนอร์ออกเดินทางส่งของและวนกลับมารับรอบใหม่เป็นลูปต่อเนื่อง
   - ซ่อนตารางตัวเลขและ Event Log เพื่อให้รับชมมุมมอง 3 มิติได้อย่างสบายตา

2) Mode: Flow Details (Linear Step-by-Step ERP Ledger):
   - จำลองการผลิตทีละขั้นตอนอย่างเคร่งครัดตามสเต็ป 1 ถึง 8
   - แสดงตัวเลขคำนวณของเสีย (Station Waste %), สรุปยอดตัดสต็อกคงเหลือใน RM WH และ Event Log บันทึกประวัติการเบิกจ่ายทุกวินาที

11. ลายสินค้าจริงและกระบวนการผลิตต่อเนื่อง (Authentic Product Pattern & Downstream Flow)
--------------------------------------------------------------------------------
- ลายสินค้าอ้างอิงจากรูปถ่ายจริง (ถุงเติมผลิตภัณฑ์ปรับผ้านุ่มสูตรเข้มข้นพิเศษ "ไฮยีน" / Hygiene Expert Care):
  • ด้านหลัง (Back Panel): แผงสีม่วงอมแดงฟิวเชีย/มาเจนต้า (#be185d), โลโก้วงรี "ไฮยีน", ข้อความรายละเอียดวิธีใช้, สัญลักษณ์เครื่องซักผ้า, กล่องบาร์โค้ดสีขาวคมชัด พร้อมมาร์คตัดเซนเซอร์ (Optical Eye-Marks) และจุดสี CMYK ที่ขอบแผ่นฟิล์ม
  • ด้านหน้า (Front Panel): ไล่เฉดสีฟ้าคราม/ไซแอนลงสู่ขาวมุก (#0284c7 -> #38bdf8 -> #ffffff), เส้นริบบิ้นสีทองคดโค้ง (#f59e0b), โลโก้อักษรประดิษฐ์ "Hygiene" สีน้ำเงินเข้มขอบเรืองแสงสีขาว, ตราเหรียญทอง 8X Freshness, ช่อดอกกุหลาบสีชมพู-ทับทิม, ป้ายระบุ REFILL 500 ml และแถบสะท้อนแสงเงา (Specular Sheen)
  • หน้าตัดม้วน (Roll Faces): วงกลมหัว-ท้ายม้วนเป็นสีชมพูอ่อน (#fbcfe8) เสมือนชั้นฟิล์มพิมพ์ลายที่ม้วนทับซ้อนกัน พร้อมแกนเพลาเหล็กสีเข้มตรงกลาง
- การส่งต่อลายสินค้าตลอดทั้งสายการผลิต (From Printing to Dispatch):
  1) ST_PRINT (Printing): ม้วนเก็บ Rewinder ด้านขวา และแผ่นฟิล์มที่วิ่งออกจากหัวพิมพ์ เป็นลายพิมพ์ Hygiene
  2) PRD WH: แท่นม้วนสเตจจิ้งทางซ้าย และม้วนที่พักรอ Curing แสดงลายม้วนพิมพ์ Hygiene
  3) ST_LAM (Laminate): ม้วน Unwinder ตัวหลัก และม้วนลามิเนต Rewinder เคลือบเงาสูง เป็นลาย Hygiene
  4) ST_SLIT (Slit): ม้วน Master Unwinder, ม้วนสลิตหน้าแคบ 4 ม้วน และพาเลทม้วนตั้ง 3 ม้วน เป็นลาย Hygiene
  5) ST_BAG (Bag Making): ม้วนคลายฟิล์มคู่ และซองสำเร็จรูป Stand-up Refill Pouch บนสายพานและในกล่อง เป็นซองพิมพ์ลาย Hygiene
  6) ST_SPOUT (Spout): ซองที่เข้าและออกจากสถานี เป็นซองมีฝาจุก Hygiene Spout Pouch (ฝาสีเขียวมรกตที่มุมบ่าซอง)
  7) Warehouse FG & Loading Yard: พาเลทสินค้าสำเร็จรูปบนแร็ค รถยก และในตู้คอนเทนเนอร์ บรรจุกล่องซองและม้วนลาย Hygiene


12. โมเดลถุงเม็ดพลาสติกวางแนวนอนและพาเลทเรียงสลับชั้นเสมือนจริง (Horizontal Resin Sacks)
--------------------------------------------------------------------------------
- ถุงเม็ดพลาสติก 25 กก. วางแนวนอนตามรูปถ่ายจริง (Horizontal 25kg Resin Sacks):
  • พื้นผิวและลวดลาย Canvas Texture ความละเอียดสูง: ผิวถุงพลาสติกทอโพลีโพรพีลีนสีขาวนวล (#f8fafc) พร้อมลายตารางเส้นทอละเอียด (#e2e8f0), แถบคาดสีกรมท่า/รอยัลบลู (#1d4ed8 -> #1e40af) พร้อมเส้นตัดสีฟ้าครามสดใส, ตัวหนังสือพิมพ์ระบุชนิดและเกรดชัดเจน "POLYMER RESIN", "VIRGIN PELLETS • BLOWN FILM GRADE", "NET WT. 25.0 KG (55.1 LBS)", รหัสล็อตผลิต "LOT: 2026-HDPE-9942A | MFI: 2.1 g/10min" และสัญลักษณ์รีไซเคิล [PE-HD 02], ขอบหัว-ท้ายมีเทปยึดรอยเย็บสีน้ำเงินเข้มและเส้นด้ายเย็บตะเข็บสีแดงประ
  • รูปทรงถุงทรงหมอนนุ่มนวลแบบมีมิติ (Pillowed Form): ตัวถุงหลักมีมิติความหนาแบบกระสอบวางนอน ขอบข้างทรงกระบอกโค้งมนทั้งสองฝั่ง ให้ความรู้สึกของกระสอบที่บรรจุเม็ดพลาสติกจนป่องแน่น พร้อมรอยพับเย็บปิดปากถุงหัว-ท้าย (Pinched Flanges) และเทปปิดตะเข็บ
- การจัดเรียงบนพาเลทไม้แบบขัดแตะสลับชั้น (Interlocking Pallet Stacking Pattern):
  • วางเรียงบนพาเลทไม้ยูโรมาตรฐาน (ขนาด 2.4m x 0.26m x 2.0m) ยกสูงเหนือพื้น ไม่ได้วางบนพื้นคอนกรีตโดยตรง
  • ชั้นที่ 1 (ล่างสุด): ถุงวางแนวนอนตามแนวแกน X จำนวน 6 ถุง (2 x 3)
  • ชั้นที่ 2: ถุงวางแนวนอนสลับขัดแตะ หมุน 90 องศา ตามแนวแกน Z จำนวน 6 ถุง (3 x 2) เพื่อล็อคกองถุงไม่ให้ล้มตามหลักความปลอดภัยคลังสินค้าจริง
  • ชั้นที่ 3: ถุงวางแนวนอนตามแนวแกน X จำนวน 6 ถุง
  • ชั้นที่ 4 (บนสุด): ถุงวางแนวนอน 4 ถุง รวมทั้งสิ้น 22 ถุงต่อพาเลท
- ใช้งานครอบคลุมทุกจุดในโรงงาน:
  1) คลังวัตถุดิบ (RM Warehouse โซนตะวันออกเฉียงใต้): ยกเลิกกล่องสี่เหลี่ยมสีขาวทรงขั้นบันไดแบบเดิม แล้วแทนที่ด้วยพาเลทไม้จริง 2 ตัว (Pallet 1 ด้านหน้า และ Pallet 2 ด้านหลัง) บรรจุกระสอบเม็ดพลาสติกวางนอนเต็มอัตรา เชื่อมต่อกับระบบแสดงผลสต็อกคงเหลือแบบไดนามิก
  2) การขนย้ายบนรถยก (Transport Cargo): เมื่อ RM Forklift หรือ Hand Pallet Truck เบิกเม็ดพลาสติกไปส่งที่เครื่องเป่าฟิล์ม (ST_BLOWN) สินค้าบนงายกจะเป็นพาเลทกระสอบแนวนอนลายพิมพ์จริง


13. ผังคลัง RM WH มีชั้นวางของ 1 แถว และมีของวางอยู่ที่พื้น (1-Row Racking & Floor Placement)
--------------------------------------------------------------------------------
- ผังชั้นวางของ 1 แถว และของวางบนพื้นตามภาพอ้างอิงจริง:
  • ชั้นวางของอุตสาหกรรม 1 แถว (ฝั่งทิศตะวันตก): เสาโครงสร้างสีน้ำเงินเข้ม (#1d4ed8), คานรับน้ำหนักสีส้ม (#f97316) และแผ่นปูพื้นชั้นวางสีขาว (#f8fafc) รวม 3 ชั้น โดยชั้นล่างและชั้นกลางจัดวางแกนกระดาษคราฟท์สีน้ำตาล (PAPERCORE) แนวตั้ง 2 แถว x 3 อัน พร้อมรูกลวงแกนเพลาสีเข้มตรงกลาง
  • สิ่งของที่จัดวางบนพื้นคอนกรีตโดยตรง (Floor Storage):
    1) กองกล่องกระดาษลูกฟูก (BOX): กล่องสีน้ำตาล 3 กล่องซ้อนกันบนพื้นคอนกรีต วางอยู่ทางขวาถัดจากแร็คทันที มีแถบเทปปิดผนึกสีขาวคาดตรงกลางผิวด้านบน
    2) กองกล่องสีขาว (SPOUT / ฝาจุก): กล่องสีขาว 2 กล่องซ้อนกัน วางอยู่บนพื้นถัดไปทางขวาของกองกล่องลูกฟูก
    3) พาเลทเม็ดพลาสติกและม้วนฟิล์ม: กองกระสอบเม็ดพลาสติกแนวนอนบนพาเลทไม้ และม้วนฟิล์มตั้งตรงในโซนข้างเคียง
    4) ถังสารเคมี: ถังหมึก ถังทำละลาย และถังกาว วางเรียงบนพื้นในโซนสารเคมี


14. รายละเอียดการทำงานของ Animation และช่องรับ-ส่งวัตถุดิบ (Animation Details & Station Demarcation Bays)
--------------------------------------------------------------------------------
- กฎความสมจริง 3 ข้อของระบบแอนิเมชันและการขนส่ง (3 Core Realism Rules):
  1) รถขนของออกมาจาก RM ใดๆ แล้วนำไปวางไว้ที่กรอบสีเหลือง (Infeed Bay) ของจะไม่อยู่กับตัวรถแล้ว:
     • เมื่อ RM Forklift ขนวัตถุดิบ (Resin, Ink, Substrate Film, Adhesive, Papercore, Box, Spout) มาถึงช่อง Infeed (กรอบสีเหลืองทางซ้าย) สินค้าจะถูกปลดออกจากงายกของรถทันที (Unmount from vehicle) และปรากฏวางอย่างเป็นระเบียบภายในกรอบสีเหลือง Infeed
  2) ถ้ามีรถหรือพนักงานมารับของจาก Output (กรอบสีเขียว Outfeed Bay) ไปใช้ต่อ ของที่ถูกยกไปจะต้องไม่อยู่ที่กรอบสีเขียวแล้ว:
     • เมื่อเครื่องจักรผลิตเสร็จ สินค้าผลผลิตจะถูกวางไว้ที่กรอบสีเขียว (Outfeed Bay ทางขวา)
     • เมื่อรถยก (Forklift) หรือพนักงานลากพาเลท (Hand Pallet Truck) เข้ามารับของจาก Outfeed ไปยังสถานีถัดไปหรือคลังสินค้า ของจะถูกยกขึ้นตัวรถทันที และเคลียร์หายไปจากกรอบสีเขียวทันที (Clear from Green Outfeed Bay)
  3) ถ้า Process ไดยังไม่มี Input เครื่องจะหมุนเบาหรือเดินเครื่องเบา ถ้ามี Input ก็จะเดินเครื่องเร็ว:
     • ระบบตรวจสอบสถานะวัตถุดิบในช่อง Infeed แบบไดนามิก (isStationInputReady):
     • หากสถานียังไม่มี Input (กรอบสีเหลืองว่างเปล่า และสถานะ IDLE): ลูกกลิ้ง เพลา และกระบอกพิมพ์จะหมุนชะลอเบาๆ แบบเดินเครื่องรอบต่ำเพื่อหล่อลื่น (Gentle Idle 1.0 rad/s) ชิ้นส่วนกลไกและแขนคนงานจะพักนิ่ง
     • ทันทีที่วัตถุดิบถูกนำมาวางในกรอบสีเหลือง Infeed หรือเข้าสู่สถานะ RUNNING: เครื่องจักรจะเร่งความเร็วเดินเครื่องเต็มกำลังทันที (Fast Active 7.2 rad/s) ลูกกลิ้งหมุนเร็ว กระบอกพิมพ์ขยับขึ้น-ลง และแขนพนักงานควบคุมเครื่องจักรจะขยับปฏิบัติงานอย่างกระฉับกระเฉง ไฟสัญญาณ Beacon เปลี่ยนเป็นสีเขียวสว่าง


15. โมเดลเครื่องเป่าฟิล์ม Blown Film Extrusion Line หลายชั้น และข้อกำหนดม้วนฟิล์มสีขาว (Blown Film Architecture & Pure White Film Rolls)
--------------------------------------------------------------------------------
- โครงสร้างเครื่องเป่าฟิล์มตามภาพอ้างอิงจริง (media_1792577328506_4e13179b.png):
  • ฝั่งขวา (+X): ระบบ Co-Extrusion ประกอบด้วยกระบอกรีดแนวนอน 3 กระบอกขนานกัน หุ้มฉนวนสีน้ำเงินรอยัลบลู (#1e40af) พร้อมแถบรัดฮีตเตอร์ มอเตอร์ขับเคลื่อนและชุดเกียร์ขนาดใหญ่ที่ด้านท้าย ด้านบนมีกรวยผสมวัตถุดิบและหอจ่ายสารเติมแต่งแบบ Gravimetric Dosing Feeder มีท่อสแตนเลสทรงกระบอกแนวตั้ง 4 ท่อต่อชุด
  • กองถุงเม็ดพลาสติก 3 ถุง: มีถุงเม็ดพลาสติก 25 กก. วางแนวนอนกองซ้อนกัน 3 ถุง (ชั้นล่าง 2 ถุง และชั้นบน 1 ถุง) วางอยู่บนพื้นข้างกรวยจ่ายวัตถุดิบของเครื่อง
  • ฐานส่วนกลาง: แท่นหัวดายทรงกลม (Die Head) และวงแหวนหล่อเย็นลมคู่ Dual-Lip Air Ring สีน้ำเงินรอยัลบลูพร้อมท่อจ่ายลม 4 ทิศทาง
  • กรงประคองฟิล์มล่างและเกลียวประคอง: กรงวงแหวนสีน้ำเงิน 3 ชั้น พร้อมลูกกลิ้งเทฟลอน 8 จุด และโครงสร้างเกลียวสีน้ำเงินโอบรอบฟิล์มช่วงล่าง
  • กระเช้าปรับขนาดฟิล์มช่วงกลาง (Calibration Basket): โครงสร้างสีขาวปรับขนาดฟิล์มแบบมอเตอร์ พร้อมแขนปรับ 8 แฉกและลูกกลิ้งซิลิโคนประคองฟองฟิล์ม และวงแหวนเซนเซอร์วัดความหนาฟิล์ม
  • ฟองฟิล์มเป่าทรงกระบอกสีขาว (White Tubular Film Bubble): ฟองฟิล์มโพลีเมอร์สีขาวโปร่งแสง (#ffffff) ทอดยาวจากวงแหวนลมขึ้นสู่ยอดหอคอย
  • หอคอยชั้นบนและชุดรีดแบน (Haul-Off Mezzanine & Collapsing Boards): ชานชาลาดาดฟ้าพร้อมราวกั้น แผงรีดฟิล์มแบบกระดานระแนง (A-Frame Slat Boards) บีบฟองฟิล์มกลมให้แบนเรียบ และลูกกลิ้งดึงฟิล์ม Nip Rollers ด้านบน
  • ทางวิ่งฟิล์มแบบซิกแซกแนวตั้ง (Descending Zig-Zag Dancer Web Path): แผ่นฟิล์มสีขาววิ่งออกจากยอดหอคอยลงมาในแนวซิกแซกผ่านลูกกลิ้งปรับความตึง (Idler Rollers) 5 ระดับ และสะพานส่งฟิล์มเข้าสู่ชุดม้วนเก็บ
  • เครื่องม้วนเก็บฟิล์มคู่แบบ Surface Winder (ฝั่งซ้าย -X): โครงตู้สีขาวตัดขอบน้ำเงินรอยัลบลู หน้าจอ HMI คอนโซลควบคุม ลูกกลิ้งกดผิว และแกนหมุนสำรอง
- ข้อกำหนดม้วนฟิล์มสีขาวทั้งหมดก่อนผ่านการพิมพ์:
  • ม้วนฟิล์มที่ผลิตออกจากเครื่อง Blown Film ต้องเป็นสีขาวเท่านั้น (White Roll)
  • ม้วนฟิล์มทั้งหมดที่ยังไม่ผ่านขั้นตอน Printing (ได้แก่ ม้วน Blown Film ในคลัง RM WH, ม้วน Purchased Film ในคลัง RM WH, ม้วนวัตถุดิบบนพาเลท และม้วนที่ติดตั้งอยู่บนแท่นคลายฟิล์ม Unwinder ของเครื่องพิมพ์) ต้องเป็นสีขาวล้วน (#ffffff / #f8fafc) ทั้งหมด 100%


16. การลบฐานรองเครื่องจักร และการปรับปรุง Logic การผลิตและตั้งเวลาการทำงาน (Base Pad Removal & Event-Driven Process Timing)
--------------------------------------------------------------------------------
- การลบฐานรองเครื่องจักรสีเข้มออก (media_1792580255743_2e7de20c.png):
  • ลบฐานแท่นยกพื้นสี่เหลี่ยมสีเทาเข้ม (14.0 x 8.4 x 0.32) ใต้เครื่องจักรออกทั้งหมด ทุกสถานี
  • เครื่องจักรตั้งอยู่บนพื้นคอนกรีตโรงงานโดยตรงอย่างสะอาดตาและสมจริง ตามภาพอ้างอิงของผู้ใช้ที่วงกลมสีแดงไว้ให้ลบออก
  • กรอบช่องแบ่งเขตสีเหลือง (Infeed Bay) และสีเขียว (Outfeed Bay) ยังคงตีเส้นเด่นชัดอยู่บนพื้นข้างเครื่องจักรเช่นเดิม
- การปรับปรุง Logic การทำงานและเงื่อนไขการผลิต (Event-Driven Logistics):
  1) ต้องมี WIP/RM input ก่อน เครื่องถึงจะทำงานได้:
     • หากช่อง Infeed สีเหลืองทางซ้ายยังไม่มีวัตถุดิบเข้ามาวาง เครื่องจักรจะยังไม่เริ่มรอบการผลิต โดยจะหมุนเดินเครื่องเบา (Idle spin 1.0 rad/s), ไฟสถานะเป็นสีเทา และพนักงานประจำเครื่องจะยังไม่ขยับแขนทำงาน
     • เมื่อรถยกหรือพนักงานนำวัตถุดิบมาวางที่กรอบสีเหลือง เครื่องจักรจะเร่งความเร็วเดินเครื่องเต็มกำลังทันที (Fast spin 7.2 rad/s, ไฟสถานะเป็นสีเขียว, พนักงานขยับแขนปฏิบัติงาน)
  2) ถ้าไม่มี Output ก็จะยังไม่สามารถส่งต่อให้กระบวนการต่อไปได้ (ต้องรอจนกว่าจะมี):
     • รถเข็น Hand Pallet Truck หรือ Forklift ขั้นตอนถัดไป จะต้องตรวจสอบช่อง Outfeed สีเขียวของสถานีก่อนหน้าเสมอ หากยังไม่มี Output ออกมาวาง จะต้องจอดรออยู่ที่จุดรับสินค้า ไม่สามารถออกวิ่งไปสถานีถัดไปได้
     • เมื่อเครื่องจักรผลิตเสร็จและของถูกปล่อยมาวางที่ช่องสีเขียว รถถึงจะยกของออกจากช่องสีเขียว (ของในช่องสีเขียวจะหายไป) แล้วนำไปส่งต่อยังช่องสีเหลืองของกระบวนการถัดไป
  3) ตั้งเวลาทำงานของแต่ละเครื่อง (ระยะเวลาใช้วัตถุดิบจนหมด และระยะเวลาผลิตเสร็จ):
     • ผู้ใช้สามารถตั้งเวลาการทำงานของแต่ละเครื่องได้ 2 ค่า (หน่วยเป็นนาที):
       - inputMin: จำนวนนาทีที่เครื่องจักรใช้งานวัตถุดิบจากช่องสีเหลืองจนหมด (เมื่อถึงเวลานี้ ของในช่องสีเหลืองจะหายไป)
       - outputMin: จำนวนนาทีที่เครื่องจักรทำงานจนผลิตเสร็จและปล่อยผลผลิตออกมาวางที่ช่องสีเขียว
     • ค่าเริ่มต้นตามมาตรฐาน (Default Timing):
       - Blown Film: ใช้ Input 15 นาที / ได้ Output 18 นาที
       - Ink Mix: ใช้ Input 10 นาที / ได้ Output 12 นาที
       - Printing: ใช้ Input 20 นาที / ได้ Output 25 นาที
       - Laminate: ใช้ Input 18 นาที / ได้ Output 22 นาที
       - Slit: ใช้ Input 12 นาที / ได้ Output 15 นาที
       - Bag: ใช้ Input 15 นาที / ได้ Output 20 นาที
       - Spout: ใช้ Input 12 นาที / ได้ Output 16 นาที
     • มีช่องปรับตั้งค่าทั้งในแถบควบคุมด้านซ้าย (#stationTimingGrid) พร้อมปุ่ม Reset default และใน Inspector Panel ด้านขวา (แสดงสถานะนับถอยหลังสด Live Countdown)
     • รองรับสมบูรณ์ทั้ง Mode: Flow Details (Linear Step-by-Step) และ Mode: Flow Only (Concurrent Digital Twin)
